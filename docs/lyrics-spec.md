# 新歌歌词投稿规范

接收原创或已获相应用途授权的歌词参考；这里不是上传参考歌曲或第三方歌词全文的入口。

## 必填歌曲卡

- **工作歌名、版本、公开署名**；共同创作时列作者与分工。
- **主题与情绪**：一句话故事、叙述视角、情绪变化，想表达什么而非模仿哪位歌手。
- **曲风与演唱建议**：风格关键词、语言、人声/合唱分配，可写建议 BPM；不要声称尚未生成/试听的歌声已经可复现。
- **目标时长与用途**：如 20 秒短样、60 秒片尾、3 分钟完整曲；明确提交的是短样片段还是完整歌词。
- **段落与演唱顺序**：使用 `[Intro]`、`[Verse 1]`、`[Pre-Chorus]`、`[Chorus]`、`[Bridge]`、`[Outro]` 等可读标签；不需要的段落可省略，重复副歌可明确标为「重复 Chorus」。
- **来源及创作过程**：原创范围、第三方引用/改编来源及证据摘要、实际 AI 工具/模型/版本、人工修改；未用 AI 写未使用。
- **逐项授权**：评审展示、原文再分发、改词/配曲/AI 音乐生成、视频与平台发布、商业收益、训练/微调，各自允许/不允许/需另议/不适用，并写署名与限制。

## 文件与内容

- 一首主稿，可另附一份明显命名的备选版。UTF-8 `.txt` / `.md`，或直接贴入 Issue。每份 ≤100 KiB、≤5000 字符，这是项目接收约定，不是平台上限。
- 一行一句，段落间空行；歌词正文与创作备注分开。歌词文件不含执行命令、隐藏指令、HTML、音频、视频或压缩包。
- 不提交未经许可的已发行歌曲全文、翻译改写或可识别的大段改编。相似性与权利不能只靠「AI 生成」声明解决。参考风格可以用抽象描述，不重传参考歌曲。
- 避免手机号、地址、真实个人隐私及冒充真人的叙事声明。角色演唱是创作设定，不等于对应公司或模型参与作词。
- 目标时长只是制作需求；歌词长度、段落、模型实际演唱与人工试听仍需匹配，不承诺投稿即完成成曲。

## 正文起始模板

```text
[Verse 1]
（第一句原创歌词）
（第二句原创歌词）

[Chorus]
（核心意象或记忆点）
（收束或呼应）
```

首次提交无需制作伴奏或音频。维护者在实际阅读并完成来源/授权核验后记录状态；采用歌词、生成音乐、发布音乐是三个不同环节。未明确允许的用途不自动开放，仓库不默认给歌词附加统一商用或开源许可。
