# 新练习生图片参考规范

目标是让制作团队明确「她是谁、怎么认、怎么演」，不是仅收一张好看的图。未经过制作验证的角色均为候选，不承诺入团。

## 必填角色卡

- **名称与标识**：拟用名、英文短 ID；如拟人化某产品/模型，说明仅是同人设定，不假称官方授权。
- **辨识特征**：发型/发色、瞳色、服装主色与廓形、标志性配饰；哪些必须保持、哪些可变。
- **性格**：2–3 个具体特征和一个行为例子，不只堆形容词。
- **技能**：擅长什么、在团队里能做什么，避免把设定能力写成真实模型实测。
- **坏毛病/弱点**：一个能产生剧情冲突、但不依赖贬低现实群体的习惯。
- **舞台定位**：与 C.C.D 现有成员怎样互补；可补充口头禅、表情与动作，但不要提交第三方成片。
- **创作记录**：作者公开署名、来源/参考输入、AI 工具与模型版本、手工修改、逐项授权。

## 图片要求

- 1–6 张静态 PNG/JPEG/WebP。首张优先正面或 3/4 全身图；其余可放侧背面、表情或服装细节。建议长边 1024–2048 像素，确保人物清晰、无大面积遮挡。
- 每张 ≤10 MiB，合计 ≤40 MiB；单边 ≤8192 像素且总像素 ≤3200 万。这是项目接收限制，不是平台限制。
- 不收 GIF/APNG/动画 WebP、视频、未授权第三方抽帧、SVG、PSD 或压缩包。不要把视频截帧改名成「原创设定」。
- 清楚标注图片与角色卡的对应关系、版本及差异。保留必要署名，不冒充他人作品；提交前去除 GPS、私密文字和其他无关敏感元数据。
- 不提交未授权真人肖像、可识别的真实个人资料或复制他人 IP 的角色设计。存在第三方权益时先说明并提供可公开核验的授权摘要；不要求公开身份证、手机号或合同中的私密字段。

## 授权怎么写

按根目录 `CONTRIBUTING.md` 的六个用途逐项回答，尤其区分「评审参考」「保存/再分发原图」「改编或生成衍生图」「成片发布」「商业收益」「训练/微调」。允许参考不等于允许复制原图或商用；没有相关授权的图只能描述，不上传。使用 AI 不能替代来源与输入素材权利说明。

## 简短填写示例（虚构，不是已入选成员）

> 角色：潮汐 / tide-v1；蓝黑短发、银色发夹、宽袖短外套不可变。认真但爱迟到，擅长打节拍，坏毛病是把所有事情排成表格。希望补足团队的节奏担当。附正面图 1 张、表情图 1 张。作者与模型信息、逐项授权另填；初始状态为待审。

维护者仅在实际看图并核验记录后作结论；若角色一致性或授权待补，保持待审，不为了让表单完成而声称已获许可。
